## ChatGPT Go 订阅多少钱？怎么扣费？

先把三档消费级订阅的价格放在一起：

- **Go：8 美元/月**（美国定价，部分市场做了本地化调价）

8 美元是这三档里最低的一档，官方也称 Go 是全球最实惠的 AI 订阅之一。

计费规则值得逐条看清楚：

1. 按月自动扣费，随时可以取消；
2. 目前 Go、Plus、Pro 都不支持年付或一次预付多月；
3. 所有购买以美元结算，只有少数国家/地区提供当地货币结算；
4. 可用的付款方式因国家/地区而异；
5. 官方明确说可能会根据早期使用情况和反馈不时调整价格，所以一切以你下单时页面显示的为准。

## ChatGPT Go 订阅常见问题

**Go 的文本聊天有限量吗？**
日常文本聊天不限量，这点和免费版一样。Go 提升的是图像生成、文件上传、数据分析等功能的额度，高峰期仍可能碰到临时限流。

**Go 包含 Think 模式吗？**
包含。网页端和移动端都能用，移动端在"+"菜单里选 Think。这个模式背后是 GPT-5.6 Luna；GPT-5.6 Sol 不在 Go 的包含范围内。

**Go 能用旧模型吗？**
不能，Go 订阅不提供传统模型的访问权限。

**有年付套餐吗？**
目前 Go、Plus、Pro 都不支持年度结算或预付多月，只能按月付。

**包含 API 额度吗？**
不包含，API 使用单独计费，和订阅套餐是两套账。

**支持群聊吗？**
支持。群聊功能已向 Free、Go、Plus、Pro 的登录用户开放，可以把最多 20 个人拉进同一个对话。你的个人记忆不会在群聊中共享，ChatGPT 在群里的回复会计入被回复那个人自己的套餐额度。

**Go 会看到广告吗？**
官方计划在美国的免费版和 Go 中测试广告，Plus 及以上保持无广告。其他地区是否跟进，目前还没有明确说法。
